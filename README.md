# SEOMind AI - Autonomous SEO Marketing SaaS

A modern, AI-powered SaaS application that analyzes websites, discovers competitors, and auto-generates/publishes SEO-optimized content to WordPress.

## 🚀 Features
- Autonomous local/global competitor discovery.
- AI-generated 30-day SEO action plans.
- One-click WordPress draft publishing.
- Professional PDF report generation.
- Secure authentication and user dashboard.

## 🛠️ Tech Stack
- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS
- **Database:** Supabase
- **Auth:** Clerk
- **AI:** Groq API (Llama 3)

## 📋 Prerequisites
- Node.js 18+ 
- Accounts on: Clerk, Supabase, Groq, and a WordPress site (for testing auto-publish).
